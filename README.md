# clicker.cdsl

clicker.cdsl is a clicker game made for the Commodiesel 64. You are free to do anything with this project, for example add more functionality, upgrades. Whatever!

# How to boot up?

Create the following files:
clicker.lua - Contents of "clicker.cdsl"
digitTextures.mod - Contents of "digitTextures.cdsl"
upgrades.mod - Contents of "upgrades.cdsl"

# Components Required

You need: 1 Joystick, 1 PC Monitor.
